# The Sacred Timeline — MCU Continuity Archive

A single-page site that catalogues the Marvel Cinematic Universe in real-world release order — every film, TV series, and one-shot — and traces the connections between them.

Two ways to browse the archive:

- **Timeline** — a chronological, scrollable list grouped by year, with connections drawn as arcs between related entries.
- **Flowchart** — a pannable, zoomable node graph of the whole continuity at once.

Filter by format (film / TV / special) or studio/origin branch, search by title, and click any entry for details on what it leads into and follows from.

Built as static HTML/CSS/JS with no build step — `index.html` holds the markup, styling, and catalogue data; `app.js` renders both views from that data.
